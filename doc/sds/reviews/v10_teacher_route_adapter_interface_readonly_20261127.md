# 路线反馈教师适配：只读接口与影响清单（2026-11-27）

**只是修订准备，不是已批准的实现或控制配方。** 当前教师准入失败、学习0，维持停止。没有选择反馈增益/速度限幅，没有修改Teacher、学生、环境指令或历史，没有新物理。

## 当前真实接口

- `V10Env._proprio()`：角速度[0:3]、重力[3:6]、请求命令[6:9]、相对关节位置[9:21]、关节速度[21:33]、上一实际动作[33:45]。env.command当前vy/wz为0。
- `BlindTeacher.forward(obs)`仅归一化并读取obs['proprio']；原始ETH权重冻结。它没有独立历史/循环状态，不读route_error或heightmap。
- `DualTeacher.label(obs, stairs_mask)`按既有单向路由选择盲走/楼梯教师；楼梯教师是S2完整Actor，会读学生真实5帧history/地图/route。
- `runtime.collect_rollout()`对同一学生快照给学生/教师，只有学生输出实际执行。5帧history始终是学生请求指令和真实执行动作，不是未执行教师预测。

## 若A范围获准，必须隔离的通道

教师私有clone `obs['proprio']`，仅其[6:9]写入经明确修订规则计算的教师内部命令；不改传给学生的同帧obs、history、map缓存、env.command、上一实际动作或奖励目标命令。学生仍看原请求及既有route3，学习专家纠偏动作。S2/stairs分支及其历史保持原合同；blind的私有命令不能混入stairs历史。

教师原始权重SHA不变不等于教师策略身份不变：wrapper公式/门控/限幅/状态必须冻结为新协议SHA，检查点/基线/缓存/paired reference需关联新身份，不能拿旧纯盲走结果冒充新wrapper已合格。

## 可用量与旧轨迹限制

| 量 | 在线来源与限制 |
|---|---|
| y偏差 | actor route_error[0]=clip(local_y/.2,−4,4)，仅在|y|≤.8可无损恢复；env实时有未截断local_y。是否允许额外privileged量须修订明确 |
| yaw误差 | route_error[1:3]为sin/cos，在线可atan2得到直线路线yaw；env也有实时root quaternion/Euler。旧20列trace没有yaw |
| 角速度 | proprio[0:3]本体角速度，wz可用；无需新传感器 |
| body速度 | privileged[:3]真实body线速度，原盲走Actor和学生Actor不直接读它；若教师wrapper使用属于新privileged反馈契约，不能悄悄加进Actor输入 |
| world速度 | env实时root_link_lin_vel_w；旧trace只存world/body XY，不是完整姿态/速度状态 |
| 足/接触 | env有真实力与三个接触/支撑定义；旧trace只safe_support，不能补推raw/非足/body mask |

旧trace缺关节状态、上一动作和完整45维输入，不能离线重新跑原盲走MLP或新wrapper得到精确动作，也不能借速度方向差当作实测yaw。

## 规则一致性与待明确边界

宽4m平台中央与普通平地在相同相对姿态/路线误差下，本体、history、相对高程和route可能同形（高度平移在高程编码中抵消，地图视野也不见边缘）。若只按隐藏platform taskID启用纠偏，同样Actor输入可能得到相互冲突的标签。规划已确认：若A获准，应按学生可观测量/请求指令定义所有blind平面运动阶段统一规则，普通平地/P/登顶后blind一致；不新增taskID输入。STAND/HOLD须单列且不得擅加移动，stairs不变。

需要明确但此文不选数值：反馈输入与坐标系、门控（包括DECEL/RESTART）、输出vy/wz限幅与变化率、停车指令下是否完全关闭、是否有状态/滤波及reset恢复、privileged速度是否使用。原始巡航vx、奖励/损失、Actor输入、课程/合格标准不应顺带改动；任何拟变化交规划及用户范围确认。
