# SDS 执行规划书｜A2 v0.8 楼顶停车、倒退下楼与楼梯中途换向

**实施对象：A2upstairs。起始模型：v0.7 正式训练 `stop_006400.pt`。**

交付目标是一套策略、一个带符号的前向速度指令。机器人始终头朝楼上，收到正速度就向上走，收到负速度就倒着下楼，收到零速度就在当前位置停稳。顶部平台和底部平地按普通平地停车。在台阶中段停车时，允许前后足处于不同高度。

实施分两部分。**先验收“平地行走停车”和“完整爬完 L40 后停车”，再开放倒退下楼和中途换向课程。** 下楼训练期间持续复测前一部分。删除原 V 速度适应课程。

## 2. 统一指令与停车协议

### 2.1 行走和换向

- 控制周期 `dt=0.02 s`，50 Hz。训练巡航速度幅值逐回合采样 `c ~ U[0.3,0.6] m/s`，评估固定为 `0.3 / 0.5 / 0.6 m/s`。`vy=0`、`wz=0`。机器人期望航向始终沿楼梯向上轴，包括倒退时。
- 环境分别保存**上层请求速度**、**当步实际送给 Actor 的速度**、**该步动作对应的速度**。奖励、评估和日志使用第三者；下一个观测使用下一步指令。不能把新的速度提前用于上一步的奖励。
- 收到停车、起步或反向请求后，从当前已执行速度 `v0` 开始，用 **100 个控制步、2 秒**线性过渡到目标 `v1`。第 `k` 步执行 `v0+(v1−v0)×k/100`，`k=1…100`。新的请求中断未完成的过渡时，从当时的实际指令重新插值。重复发送相同目标不重启计时。
- 例如 `+0.5→−0.5`，第 50 步为 `0`，第 100 步为 `−0.5`；`+0.5→0` 则第 100 步到零。单纯换向经过零的那一帧不会触发停车成功或驻留奖励。
- 提供可回放的有符号速度请求接口，支持在任意控制边界接收 `[-0.6,+0.6]` 内有限值。正式训练和验收覆盖上述三档巡航速度、零速及过渡过程。修改当前只接受非负速度的入口校验。

### 2.2 平地、楼顶、楼底与台阶中段

| 地点 | 何时下发停车请求 | 目标行为 |
|---|---|---|
| 普通平地 | 按巡航指令行走满 8 秒；评估要求前进净位移 `≥0.8×c×8`，行走期间 `max abs(y)≤0.20 m`、`max abs(yaw)≤10°` | 2 秒减速，零速保持 20 秒 |
| 楼顶平台 | 首次满足 v0.7 已有的安全登顶条件 | 在同一回合继续仿真，2 秒减速，零速保持 20 秒 |
| 楼底平地 | 倒退下最后一级，机身 `local_x≤−0.80 m`、`abs(y)≤0.20 m`，四脚均位于 `x<0` 的底部平地区，最近 50 帧各脚均有该地面有效支撑、当帧至少两脚有效支撑，连续 5 帧 | 2 秒减速，零速保持 20 秒 |
| 台阶中段 | 由课程发出零速请求，使用第 5 节的位置安排 | 2 秒减速，零速保持 6 秒；随后按新指令重新起步 |

有效支撑使用对应地形的足端接触力 `>5 N`。顶部和底部的实际支撑面必须与指定平台或地面一致。台阶中段允许四脚接触不同级踏面。整个过程中真实运行策略及物理仿真，不重置躯体、不锁足、不直接写速度、不调用独立站姿控制器。

### 2.3 站稳怎么算

**平地、楼顶和楼底**采用已在 6400 平地停车案例中验证过的一组尺度。完整执行 20 秒零指令，对**最后 10 秒**进行以下联合判定。水平速度和 XY 漂移取世界水平面，姿态取机身姿态，高度取相对脚下地形高度。

| 指标 | 通过阈值 |
|---|---:|
| 平均水平速度 | `≤0.05 m/s` |
| 最大水平速度 | `≤0.10 m/s` |
| 最大绝对横滚、最大绝对俯仰 | 各 `≤10°` |
| 窗口首尾 XY 净漂移 | `≤0.10 m` |
| 最大机身角速度模长 | `≤0.25 rad/s` |
| 最低相对机身高度 | `≥0.25 m` |
| 平均足端速度，四脚等权 | `≤0.05 m/s` |
| 四足同时有效支撑的帧占比 | `≥90%` |

楼顶还要求判定窗口内四脚均在原平台安全矩形内。登顶后机身越出平台物理边界即判失败；楼底按底部地面边界与原安全失败规则执行。任何物理失败优先于成功。**平地停车、楼顶停车、楼底停车使用同一套运动学判据。**

**台阶中段**对最后 **3 秒**判稳。沿用上表的速度、漂移、角速度、足速与接触占比指标，另要求 `abs(roll)≤12°`、`abs(pitch)≤50°`、`abs(yaw)≤15°`。高度用机身世界高度减去四个实际支撑踏面高度的中位数，最低 `≥0.22 m`；不足四足同时接触的帧使用各足最近一次有效支撑高度，进入停车段后须先取得每足有效记录。该定义允许前后脚高低不同，也防止躯体趴在台阶上被当成站立。零速期间机身须留在楼梯中段；后续重新起步和完成任务同样计入整例验收。

## 3. 奖励、成功与失败

### 3.1 奖励变更表

连续项按 `dt×权重×原始量` 结算。沿用 v0.7 的动作、关节、接触、路线中心、航向等其余奖励。以下为 v0.8 的完整差异。

| 项目 | v0.7 | v0.8 |
|---|---|---|
| 线速度跟踪 | 权重 `+1.5`，原课程只使用正巡航速度 | 公式继续使用 `1.5×exp(−[(vx_b−c_exec)²+vy_b²]/0.25)`，直接比较有符号的实际指令。倒退 `−0.5` 且实际 `−0.5` 得满额 |
| 位移 | `+0.4×Δx` | 恒定巡航时改为 `+0.4×sign(c_exec)×Δx`。停车、零速保持及所有 100 步指令过渡期间为 `0`。错误方向的巡航位移产生负奖励 |
| 平面姿态 | 全程原横滚约束 `−5×g_y²` | 保留原项。仅在普通平地、顶部平台、底部平地的**停车减速与零速保持**期间新增 `−5×g_x²`。台阶中段停车沿用原横滚项，允许机身随高差俯仰 |
| 稳定角速度 | `−0.05×(ωx²+ωy²)` | 巡航、起步及直接换向沿用 `−0.05`。所有停车减速和零速驻留期间替换为 `−0.20` |
| 迈步腾空 | 原 `feet_air_time` 权重 `+0.2` | 巡航、起步、直接换向沿用原值。发出停车请求直到下一次起步前，权重为 `0`；起步时清理停车期间的腾空计时，避免一次性补发 |
| 稳定站立 | 无 | 仅在请求保持零速且实际速度指令已到零时生效。满足相应地点的即时姿态、高度、角速度、水平速度 `≤0.05 m/s` 和四足有效支撑时，每步 `+1.0×dt`。驻留时长固定，不能靠延长回合多拿奖励 |
| 到达 | 登顶即 `+10` 并结束 | 各回合**最终目的地**首次合格到达时给 `+2`，继续停车。普通平地必须完成前进要求。中间停车点、换向点和往返任务的中间楼顶只记事件，不发到达奖 |
| 最终成功 | 与旧登顶事件合并 | 完成规定的全部动作并通过最后站稳窗口，一次性 `+8` 后结束 |
| 失败 | 原物理失败 `−10` | 原物理失败保留；任务超时、指定中停失败、最终未站稳也各按本回合一次 `−10` 结束。同一步一旦失败不再发到达或成功奖励 |

这里保留正速度爬楼时的原奖励，目的是保护 6400 已有的上楼能力。倒退和上楼共用相同的速度跟踪方式。**新增俯仰回正只在水平停车面生效**，避免为了楼顶站直而迫使机器人在 20 cm 高台阶上也把机身压平。

### 3.2 原系统必须一起修正的四个地方

1. **旧登顶 `done` 改为任务事件。** 记录到达时的真实状态，保留 Actor 历史以及生效的动作、姿态和足端接触，下一控制步开始减速。长往返任务允许先上楼、楼顶停稳，再倒退回楼底。
2. **旧速度和停滞逻辑有正方向假设。** 取消“一整个回合指令恒定”的断言，停滞诊断只在非零恒速巡航片段采样。每次片段开始独立建窗，倒退使用 `sign(c)×Δx` 计进展。零速驻留、减速、换向不能触发旧停滞报警。
3. **超时按路段计算。** 完整上行和下行分别用原地形超时公式，分母取巡航速度**幅值**；多路段任务逐段给时。任一非零行程段最多使用一次该地形完整单程时限。每次指令过渡额外 100 步，端点零速额外 1000 步，中停零速额外 300 步，每次事件只加一次。不得将负速度送入原 `clamp_min(0.01)` 当成超慢行走。
4. **后方高程图保持原坐标语义。** 现有网格由 `−0.8+(i+0.5)×0.05` 生成，机身后方已有采样点。继续使用同一高度图和权重；验证后方由高到低的踏面序列能被真实采样。禁止为了倒退旋转机器人目标航向、翻转地图或交换前后腿动作。

所有阶段使用同一策略。标记为“保留”的环境也参与正常学习，评估使用独立环境。阶段晋级须通过第 6 节门禁，前一阶段剩余预算不自动转入下一阶段。

| 阶段 | 512 个训练环境的固定构成 | 新增更新上限 | 晋级目标 |
|---|---|---:|---|
| A　上楼后停车 | 320 个 L40 完整上楼停车、128 个普通平地停车、64 个 H00 上楼停车 | 4000 | L40 与平地三速均通过 |
| B　出生扰动巩固 | 分配同 A。训练出生范围在前 400 更新内按原 R 规则扩大，门禁始终使用完整扩张范围 | 2000 | 扩张出生条件下 L40 与平地三速均通过；至此才开放下楼训练 |
| C　短楼梯倒退 | 256 个 D20 顶部起步倒退到底、128 个 L40 上楼停车、96 个平地停车、32 个 H00 倒退到底 | 2000 | 六级 D20 倒退到底并停稳，同时通过前两项保留门禁 |
| D　完整倒下 L40 | 256 个 L40 顶部起步倒退到底、128 个 L40 上楼停车、96 个平地停车、32 个 D20 倒退 | 4000 | 40 级完整倒下，楼底停稳；上楼和平地继续通过 |

总上限 **新增 18,000 次更新**；来源 6400，加总后全局更新编号最大 **24,400**。正常提前通过即可结束。按 512 环境、48 步 rollout，每次更新 **24,576 个控制样本**，满额新增 **442,368,000 个控制样本**。H00 单项不否决正式结果，但工程异常仍须按真实原因处理。

训练沿用 `seed=42`、评估最多 8 并行、PPO 每次更新 5 个 epoch × 4 个 minibatch、`γ=0.99`、GAE `λ=0.95`、clip `0.2`、entropy `0.003`、梯度裁剪 `1.0` 及原自适应学习率规则。每 50 次更新诊断，每 100 次保存和评估。**V 课程、V 最低驻留更新数和 V 晋级依赖全部删除。**

## 5. 怎样真正训练“在台阶上任意前进后退”

只练“从楼顶倒下去”无法证明机器人在中间听得懂换向指令。阶段 E 的 256 个中途指令环境均分为以下 **4 类，每类 64 个**。以下位置使用楼梯水平长度比例 `p=x/(N×踏深)`，移动中首次按目标方向越过指定位置才触发下一条指令。

| 脚本 | 完整任务 |
|---|---|
| E1　上行直接换向 | 楼底向上 → 在中上段发负速度 → 平滑换向 → 倒退到底 → 停稳 |
| E2　下行直接换向 | 楼顶倒退向下 → 在中下段发正速度 → 平滑换向 → 正向回顶 → 停稳 |
| E3　中停后同向或反向 | 楼底上行或楼顶下行，各占一半 → 在中段停稳 6 秒 → 同向继续或反向返回，各占一半 → 到达相应端点 → 停稳。四种组合等额 |
| E4　完整连续往返 | 从楼底正向上楼 → 楼顶减速并站稳 20 秒 → 原地接收负速度，2 秒起步 → 倒退下完整 40 级 → 楼底停稳 20 秒。全程单一物理回合 |

E1 触发位置训练范围 `p∈[0.45,0.75]`，E2 为 `[0.25,0.55]`，E3 为 `[0.30,0.70]`，各回合均匀采样。测试位置依次循环取相应区间的下端点、中点、上端点。**换向后的第一段有效巡航必须沿新方向净移动至少 0.60 m，且在发出新指令后 8 秒内完成**；不得通过一直停车或继续沿旧方向走来通过。动作接口能在任意控制步响应新请求；上述区间界定本版有量化证据的楼梯中段范围。

顶部起步的倒退病例，机身生成在 `x=x_top+1.00 m`、朝上坡轴，横向偏差与航向偏差沿用所在阶段出生分布，初始姿态使用原默认站姿，机身高度按真实顶面高度设置。初始四脚必须位于顶部平台。**从顶部初始化只适用于下楼专项病例；E4 必须靠策略亲自从楼底爬到顶部，再从自己的停车状态倒退起步。** 这是专项练习与完整效果验收的区别。

## 6. 门禁、最终验收与视频

### 6.1 训练前基线

冻结 6400 来源 SHA、v0.8 配方、地形和病例表。先用**零学习**评估同一原权重的平地停车、L40 上楼停车、D20 与 L40 倒退停车。每任务每速 5 例，记录失败发生在哪一段。基线用于分辨原模型已具备的能力；不以倒退基线差为由取消后续课程。

### 6.2 每阶段晋级

- 每 100 次更新评估。A/B 要求平地与 L40 上楼停车均三速各 `≥18/20`。C 增加 D20 下楼，D 增加 L40 下楼；两者均保留平地和 L40 上楼门禁。E 要求平地、L40 上楼、L40 下楼和 E1–E4 七类任务各自达标。
- 同一阶段连续两次完整门禁通过才晋级。H00 每 200 次评估每速 5 例，仅报告。阶段上限耗尽仍未通过，保留终点 checkpoint 和证据，以具体未通过任务结束，不自动扩预算或改阈值。
- 使用确定性策略评估。各类任务按速度、脚本和初始位置独立统计，病例种子与明细在首次学习前冻结。工程错误、无效观测、原始数据缺失须单列，不能记为策略摔倒。

### 6.3 最终验收

使用独立冻结病例，在 B 的完整扩张出生范围内评估。顶端专项出生使用上述平台内中心位置与扩张横向、航向扰动。以下七类各测三档速度，每组 **100 例**，合计 **2100 例**：

1. 普通平地行走、停车、站稳；
2. 完整正向上 L40，顶部停稳；
3. 楼顶起步倒退下完整 L40，底部停稳；
4. E1 上行中直接换向；
5. E2 下行中直接换向；
6. E3 台阶中停再走，四种组合每速各 25 例；
7. E4 楼底出发、完整上楼、顶部站稳、倒退下楼、底部站稳。

**每类每速均须 `≥95/100`**。E3 另外要求四种组合分别 `≥23/25`。所有倒退或换向病例，在楼梯行走区间内要求机身相对上坡轴 `abs(yaw)≤30°`；超过即该例失败，防止策略掉头后用正向步态下楼。视频和结果分别报告物理失败、方向错误、不能按令换向、中停漂移、抵达后倾倒、超时。
