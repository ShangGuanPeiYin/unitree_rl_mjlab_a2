## 3. 控制、观测与帧时序

### 3.1 固定配置

| 参数 | 数值 |
|---|---:|
| 控制周期 | 0.02 s |
| 物理周期 | 0.005 s |
| 每控制步物理子步 | 4 |
| 地图更新频率 | 10 Hz |
| 历史长度 | 5帧 |
| 动作维度 | 12 |
| 训练seed | 42 |
| 巡航速度 | 0.3、0.5、0.6 m/s |
| 横向速度指令 | 0 |
| 偏航角速度指令 | 0 |
| 动作目标 | `q_target = q0 + 0.25 × action` |

机器人资产、关节顺序、PD、碰撞与名义动力学使用现有S2有效配置。正式实施前输出展开后的物理配置与摘要，所有教师和学生评估使用同一物理契约。

不得为节省显存改变物理精度、地图、机器人或控制频率。

### 3.2 Actor输入

- 本体感知：45维。
- 历史：`5×45`。
- 高程图：`3×40×30`。
- 路线误差：3维。

本体顺序：

```text
角速度3 + 投影重力3 + 指令3
+ 相对默认关节位置12 + 关节速度12
+ 上一实际执行动作12
```

路线误差：

```text
[clip(local_y/0.20,-4,4), sin(yaw_error), cos(yaw_error)]
```

保留该理想路线信息，不声称实现无路线输入的自主导航。不得新增教师编号、任务编号或课程编号作为Actor输入。

### 3.3 唯一控制帧协议

一条transition定义为：

\[
(o_t,a_t,r_t,o_{t+1},done_t)
\]

按以下顺序执行：

1. `o_t`包含当前任务状态对应的指令`c_t`及真实上一执行动作`a_{t-1}`。
2. 本帧`proprio_t`仅追加一次到历史；地图缓存仅按实际时钟推进一次。
3. 教师、学生、Critic重复查询同一个只读观测快照。
4. 执行`a_t`及4个物理子步，获得`s_{t+1}`。
5. 检查物理失败，再检测登顶、距离目标和时间事件。
6. 计算`r_t`：
   - 速度、姿态、接触等使用`s_{t+1}`。
   - 指令、相位、`g_level`使用动作执行前锁存的`t`时刻值。
   - 动作变化使用`a_t-a_{t-1}`。
   - 位移使用`x_{t+1}-x_t`。
   - 本次执行导致的登顶、成功或失败记入本条transition。
7. 事件影响下一动作的指令和教师，随后构造`o_{t+1}`。

因此：

- 导致登顶的动作获得登顶奖励，下一动作切换教师。
- 触发停车前的最后一个巡航动作仍按巡航相位结算。
- 同帧失败屏蔽登顶和成功奖励。
- 不得将事件重复发送到下一条transition。
- 重复前向或bootstrap读取不得再次推进历史。

reset时：

- 上一动作为零。
- 用当前指令构造`proprio_0`。
- 五帧历史均填充`proprio_0`。
- 地图重新查询，接触和任务计时清零。

### 3.4 地图编码

维持：

- 0.05 m网格。
- 前后`[-0.8,1.2] m`。
- 横向`[-0.75,0.75] m`。

\[
h=\operatorname{clip}\left(\frac{H_{\mathrm{measurement}}-z_{\mathrm{base}}}{1.5},-1,1\right)
\]

有效点刷新年龄为0，之后随控制时间增长；无效点恒为`[0,0,1]`。每5个控制步刷新一次。

不得把深落差统一改成无效或平面。教师切换不改变学生地图。

## 5. 任务、指令及教师路由

### 5.1 六类任务

| 任务 | 流程 |
|---|---|
| F_WALK | 平地持续走20 s |
| F_STAND | 零速起始站立20 s |
| F_STOP | 走8 s → 减速 → HOLD20 s → 再走5 s |
| P_WALK | 平台从出生位置前进10 m |
| P_STOP | 平台前进5 m → 减速 → HOLD20 s → 从重启位置再前进5 m |
| S_ROUTE | 爬楼至登顶；按课程结束或继续平台路线 |

每种正速度任务均衡使用0.3、0.5、0.6 m/s。

两种停车方式均衡：

- 突变：下一动作收到零指令。
- 渐变：100个控制间隔内线性降至零：

\[
c_j=c_0(1-j/100),\quad j=0,\ldots,100
\]

首次收到零指令后执行1000个完整HOLD控制间隔，即20 s。减速不计入HOLD。重新起步直接恢复原巡航速度，不增加隐藏加速课程。

### 5.2 超时

所有上限转换为`ceil(T/0.02)`步。

- F_WALK/F_STAND：正常20 s，硬防护20.02 s。
- F_STOP：正常33/35 s，硬防护33.02/35.02 s。
- 每个平台行走段：

\[
T_{\max}=d/v+10\ \mathrm{s}
\]

- 楼梯接近、攀爬：

\[
T_{\max}=(0.2N+2.1)/v+15\ \mathrm{s}
\]

完整路线总上限为各段上限加减速、HOLD时间。正常结束先结算质量，不能误记timeout；未完成目标的timeout为失败。

### 5.3 教师选择

- F、P任务：`T_blind`。
- 楼梯接近、攀爬、切换前：`T_stairs`。
- 登顶切换后：`T_blind`。

登顶条件：

1. 四足XY均在顶部平台内缩0.042 m区域。
2. 四足底部高度均≥平台顶高−0.02 m。
3. 至少两足当前具有平台顶面的向上法向力>5 N。
4. 上述条件连续两个控制帧成立。

第二个合格动作后状态产生登顶事件：

- 奖励计入刚结束的transition。
- 下一动作使用盲走教师。
- 锁存该状态机身x为平台距离起点。
- `g_level`从0开始。
- 不重置地图、历史和动作状态。

## 6. 接触、支撑与失败规则

### 6.1 三套接触量必须分开

**真实接触`C_raw`**

足部真实接触力向量范数>5 N。它表示物理接触，可包含侧面接触，不等于有效承重。

**奖励接触`C_reward`**

\[
C_{\mathrm{reward},t}=C_{\mathrm{raw},t}\lor C_{\mathrm{raw},t-1}
\]

reset时上一raw为false。腾空、滑移、抬脚奖励只使用这一变量，不混入安全内缩判据。

**安全支撑`safe_support`**

同时满足：

- 当前及上一帧真实水平顶面向上力>5 N。
- 当前足点位于对应真实、同高、连通顶面并集内缩0.042 m区域。

不得跨洞填补支撑面。该量只用于稳定站立及支撑质量。登顶使用第5.3节规定的当前顶面力与两帧整体条件。

### 6.2 测量高度与预期路面分离

- `H_measurement(x,y)`：真实几何查询，用于地图及高度奖励。
- `H_route(x)`：路线预期支撑高度，仅用于跌落保护。

预期高度：

\[
H_{\mathrm{route}}=
\begin{cases}
0,&普通平地\\
H,&独立平台\\
0,&楼梯路线x<0\\
0.2\min(\lfloor x/0.2\rfloor+1,N),&0\le x<0.2N\\
0.2N,&楼梯顶部
\end{cases}
\]

所有任务均执行：

\[
\mathrm{fall}=[z_{\mathrm{base}}<H_{\mathrm{route}}-0.50]
\]

该参考面不能随机器人横向掉出平台而下降为低地地面。

### 6.3 走廊越界

检测机身中心XY，严格越界才触发，边界相等不触发：

| 区域 | 允许范围 |
|---|---|
| 普通平地 | x∈[-2,22]，|y|≤4 |
| 独立平台 | x∈[0,14]，|y|≤W/2 |
| 楼梯接近 | x∈[-2,0)，|y|≤2 |
| 楼梯段 | x∈[0,0.2N)，|y|≤0.4 |
| 顶部平台 | x∈[0.2N,0.2N+14]，|y|≤W/2 |

机身走廊不使用0.042 m内缩。足端进入内缩之外不直接等同于物理跌落，仍按实际接触和支撑质量判断。

### 6.4 其他失败

- 机身真实接触。
- 非足部接触力>10 N持续0.1 s。
- roll或pitch绝对值>70°。
- 上述跌落、走廊越界。
- 任务超时。

物理失败立即终止。质量不可逆违规锁存，正常任务终点只能判失败，不能恢复为成功。

非有限状态、接触容量溢出属于工程异常：停止运行，不混作普通行为失败参与成功率。

### 7.2 资源选择

- 无OOM、非有限或容量错误。

## 8. DAgger数据与损失

### 8.1 采集

- 学生确定性动作控制环境。
- 教师只标注，不接管、不混合动作。
- 每条保存同帧学生观测、教师12维均值动作、任务、教师身份、病例、回合及控制步。
- 观测必须复制快照，不能引用可变环境缓冲区。
- 记录每任务有效轨迹长度、失败比例和教师标签覆盖。

### 8.2 聚合

六任务各32,768条reservoir，总196,608条：

- 标准reservoir sampling。
- CPU、FP32观测及标签。
- 保存采样计数和RNG。
- 不保存计算图。

每个逻辑批3072条：

- 每任务512条。
- 当前rollout256条、历史256条。
- 历史不足用当轮补足，允许有放回。
- 本轮更新结束后才把当前rollout并入历史。

### 8.3 损失

\[
L_k=\frac1{|B_k|}\sum_{i\in B_k}
\frac1{12}\sum_j(\mu_{\theta,j}(o_i)-a^T_{i,j})^2
\]

\[
L_D=\frac16\sum_{k=1}^{6}L_k
\]

六任务等权。环境分配控制采集比例，不替代损失权重。

DAgger不使用奖励更新Actor或Critic，不新增其他正则项。

### 8.4 优化

- Adam，LR=`3e-5`固定。
- betas=`(0.9,0.999)`，eps=`1e-8`。
- weight decay=0。
- grad clip=1.0。
- FP32，关闭AMP。
- 微批≤256。
- 1024环境每轮20次逻辑更新；512每轮10次。
- 整个逻辑批累计后一次裁剪、一次Adam。

微批必须按完整逻辑批分母累积，不能将各微批mean直接相加。

## 9. PPO流程与保持损失

### 9.1 P0与P1

P0：

- D3全任务。
- Actor冻结，标准差0.10。
- 采集新的高斯策略轨迹。
- 只更新Critic，不施加Actor、entropy或保持梯度。
- 结束保存可回退状态，不称行为验收通过。

P1：

- Actor、Critic及标准差联合更新。
- D3地形、任务比例保持。
- 不启用S3。

### 9.2 参数

| 项目 | 数值 |
|---|---:|
| rollout | 48 |
| epochs | 5 |
| 每epoch minibatch | 4 |
| 微批 | ≤256 |
| γ / GAE λ | 0.99 / 0.95 |
| policy/value clip | 0.20 / 0.20 |
| value系数 | 1.0 |
| entropy系数 | 0.003 |
| LR | 3e-5固定 |
| Adam betas / eps | 0.9、0.999 / 1e-8 |
| weight decay | 0 |
| grad clip | 1.0 |

每epoch无放回重排完整`N×48`样本，等分4批，每条新样本每epoch恰好使用一次。

- 优势在全rollout归一化一次，eps=`1e-8`。
- 不归一化奖励或return。
- policy/value/entropy按逻辑批样本数平均。
- entropy先对12维求和，再对batch平均。
- 标准差每次Adam后投影。
- KL只记录，不隐式调整学习率。

采样动作和旧log-prob对应。保留现有执行限幅并记录，但不得用限幅动作替换原采样动作后计算错误概率。

### 9.3 PPO损失

\[
L_{\mathrm{clip}}
=-E[\min(\rho A,\operatorname{clip}(\rho,0.8,1.2)A)]
\]

\[
L_V=E[\max((V-R)^2,(V_{\mathrm{old}}+
\operatorname{clip}(V-V_{\mathrm{old}},-0.2,0.2)-R)^2)]
\]

每次逻辑更新从冻结最终DAgger reservoir抽取六任务各256条，使用`T_keep`重新标注：

\[
L_{\mathrm{keep}}
=\frac16\sum_kE_{B_k}
[\|\mu_\theta(o)-\mu_{\mathrm{keep}}(o)\|^2/12]
\]

\[
L_{\mathrm{PPO,total}}
=L_{\mathrm{clip}}+L_V-0.003H+1.0L_{\mathrm{keep}}
\]

保持项与PPO梯度累计后统一裁剪、一次Adam。

旧数据只用于保持损失，不进入PPO优势、Value target或importance ratio。保持目标不是旧盲走/S2标签。

同预算下两档PPO的Adam次数不同，必须报告，不能宣称两档训练严格等价。

## 10. PPO奖励规范

### 10.1 总式

\[
r_t=0.02\sum_iw_if_i
+0.4\Delta xI_{\mathrm{cruise}}
+2I_{\mathrm{top}}
+8I_{\mathrm{success}}
-10I_{\mathrm{failure}}
\]

- 连续项只乘一次dt。
- 位移不再乘dt。
- top/success/failure为一次性事件。
- 同帧失败优先。
- timeout为失败。
- 独立平地、平台不领取top奖励。
- 不增加存活奖励。

巡航列：WALK、CLIMB、POST_WALK、RESTART。  
停车列：STAND、DECEL、HOLD。

### 10.2 连续项

下表接触变量统一为`C_reward`。

| 项目 | 未加权公式 | 巡航 | 停车 |
|---|---|---:|---:|
| 线速度跟踪 | \(e^{-[(v_{bx}-c)^2+v_{by}^2]/0.25}\) | 1.5 | 1.5 |
| 偏航速度 | \(e^{-\omega_z^2/0.25}\) | 0.8 | 0.8 |
| 竖直速度 | \(\max(|v_{bz}|-0.15,0)^2\) | −1 | −1 |
| roll | \(g_y^2\) | −5 | −5 |
| 平面pitch | \(g_{\mathrm{level}}g_x^2\) | −5 | −5 |
| 机身高度 | \((z-H_{\mathrm{measurement}}-0.4)^2\) | −0.1 | −0.1 |
| 动作变化 | \(\sum(a_t-a_{t-1})^2\) | −0.01 | −0.01 |
| 默认姿态 | \(\sum|q-q_0|\) | −0.05 | −0.05 |
| 关节加速度 | \(\sum[(\dot q_t-\dot q_{t-1})/0.02]^2\) | −2.5e−7 | −2.5e−7 |
| 关节速度 | \(\sum\dot q^2\) | −5e−4 | −5e−4 |
| roll/pitch角速度 | \(\omega_x^2+\omega_y^2\) | −0.05 | −0.20 |
| 腾空时间 | 下文定义 | 0.2 | 0 |
| 滑移 | \(\sum C_{\mathrm{reward}}\|v_{\mathrm{foot},xy}\|^2\) | −0.15 | −0.15 |
| 抬脚误差 | \(\sum(1-C_{\mathrm{reward}})(h_f-h_f^*)^2\|v_{\mathrm{foot},xy}\|\) | −0.5 | −0.5 |
| 关节跟踪 | \(\sum(q_{\mathrm{applied}}-q)^2\) | −0.1 | −0.1 |
| 横向位置 | \(\min[(y/0.2)^2,4]\) | −0.5 | −0.5 |
| 朝向 | \(1-\cos e_\psi\) | −0.5 | −0.5 |
| 软限位 | \(\sum[\max(q_{\mathrm{lo}}-q,0)+\max(q-q_{\mathrm{hi}},0)]\) | −10 | −10 |
| 平面超速 | \(g_{\mathrm{level}}\max(v_{\mathrm{heading}}-c-0.15,0)^2\) | −2 | −2 |
| 稳定站立 | \(I_{\mathrm{stable}}I_{|c|\le10^{-7}}\) | 0 | 1 |

`v_heading`为世界速度沿当前水平朝向的投影；`Δx`为路线纵向净位移。

### 10.3 辅助量

**腾空：**

- 计时与落地边沿均使用`C_reward`。
- 曾建立奖励接触后，无奖励接触每步累计0.02 s。
- 奖励接触恢复时，以该足已有腾空时间结算`T_air−0.10`，之后清零。
- 初始下落不算有效腾空。
- DECEL/STAND/HOLD清空腾空累计和落地状态；重启不结算跨停车阶段的腾空。

该滤波形式与旧实现一致，但计时统一改按`C_reward`，与旧raw计时可能相差一个0.02 s控制步。这是显式配方变化，不声称完全沿用旧腾空奖励。

**足底高度：**

\[
h_f=\operatorname{clip}(z_{\mathrm{site}}-0.032-H_f,-0.05,1.5)
\]

无有效表面填1.5 m并保留无效标记。平地/平台目标0.075 m，楼梯目标0.22 m；按实际足下表面判断。

**机身高度：**

用实际测量面，不用`H_route`替代。无有效面时高度误差填1.5 m，未加权平方项为2.25。

**软限位：**

取现有硬限位中点及半范围的0.9倍。必须由真实关节状态计算，不能填零。

**水平门控：**

- 普通平地、独立平台：1。
- 楼梯区、混合跨阶：0。
- 接近区四足投影均在普通平地：1。
- 登顶后下一动作门控0，之后每步增加1/25，最大1。
- 四足投影离开顶部有效平台则归零；正常腾空不归零。

**稳定站立：**

同时满足：

- 世界水平速度≤0.05 m/s。
- roll/pitch≤10°。
- 总角速度≤0.25 rad/s。
- 机身离支撑面≥0.30 m。
- 四足均`safe_support`。
- 四足平均水平速度≤0.05 m/s。

指令为零不等于稳定站立。

### 10.4 成功与bootstrap

完整任务质量合格才支付成功奖励。物理失败、质量失败终点和timeout均为terminal，不bootstrap。

rollout截断不是terminal，使用真实末观测bootstrap；GAE不得跨reset传播。

\[

|---|---|

### 11.7 晋级与终验

### 11.8 PPO回退

- 尚无通过状态时，恢复P0结束状态，明确其不是合格PPO模型。
- `T_keep`不变。

- 不改学习率、奖励、标准差范围和保持系数。
- 第三次需要回退时停止报告。

PPO失败时保留合格DAgger模型，但不宣称完成PPO验收。
