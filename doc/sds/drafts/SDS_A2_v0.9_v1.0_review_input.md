### 3.2 网络迁移

原三层卷积后为 `32×6×4`，新图对应 `32×5×4`。

必须修改：

- Actor地图全连接层：768→64 改为640→64。
- Critic地图全连接层：768→64 改为640→64。

其他层维度不变。

两个变化的权重矩阵按以下方式初始化：

1. 原矩阵展开为 `[64,32,6,4]`。
2. 长度轴六个位置汇总为五个位置。
3. 新位置j对应旧坐标区间`[6j/5,6(j+1)/5]`。
4. 以该区间与旧单位区间的重叠长度作为权重系数，对旧权重求和。
5. 保留偏置，恢复为`[64,640]`。

该方法保留常量空间特征的权重和，但不保证真实网络动作等价。

除这两个矩阵外，所有模型参数和归一化状态逐项复制。必须提供迁移清单，证明没有遗漏或随机重建其他层。

## 4. 第二阶段：诊断、持续行走、停车

**课程数量：4 个。**

### 4.1 地形及任务定义

楼梯：

- 阶高0.20 m。
- 阶深0.20 m。
- 梯宽0.80 m。
- 前方接近平地保持原设置。

后方平台：

- 长20 m。
- 宽0.8 m或4 m，各50%。

普通平地使用与基线相同的普通平地，不将窄高台算成普通平地。

任务分为：

- `flat_walk`：普通平地行走20秒。
- `flat_stop`：前进8秒，停车，保持20秒。
- `stairs_walk`：上楼后在平台继续走指定距离。
- `stairs_stop`：上楼后走指定距离，再停车并保持20秒。
- `platform_walk`：从平台正常默认站姿起步，持续走指定距离。
- `platform_stop`：平台起步、行走、停车。

平台直接起步在平台前缘后1米，按真实顶面设置机身高度，不从楼底高度直接生成。该专项不能替代完整上楼验收。

### 4.2 指令、里程碑与结束规则

完整流程：

```text
APPROACH → CLIMB → TOP_TRANSITION → POST_WALK → DECEL → HOLD → SUCCESS
```

- 上楼成功条件仅生成一次`top_arrived`事件。
- `top_arrived`之后不reset。
- 以该事件时机身位置作为后续行走距离起点。
- 不停车病例走够距离后才成功。
- 停车病例走够距离后发零速请求，完成保持窗口后才成功。

指令：

- 突变：下一次策略调用直接收到零速。
- 渐变：100个控制步，由当前速度线性降至0；最后一个过渡步必须为0。
- 二者各50%。
- `vy=wz=0`。

明确记录：

- `c_request`：外部请求目标。
- `c_exec`：本控制步实际送入Actor的速度。
- `a_request`：Actor输出。
- `a_applied`：真正施加给执行器的动作。

停车恢复时间从`c_exec`首次为零开始计算，不能因为后续动作延迟而重新推迟起算点。

保持20秒，最后10秒为主要站立评价窗口。

任务超时：

\[
T_{\max}
=
\frac{2\left(L_{\text{approach}}+
N\sqrt{h^2+d^2}+D_{\text{post}}\right)}{v}
+T_{\text{ramp}}+T_{\text{hold}}+10
\]

- `L_approach`取实际出生点到第一阶的距离。
- 平台起步任务上楼项为0。
- `T_ramp`为0或2秒。
- `T_hold`为0或20秒。
- 转换为控制步时向上取整。

登顶奖励不能替代最终任务成功。

\[
r_t=
0.02\sum_i w_i f_i
+0.4\Delta x\,I_{\text{cruise}}
+2I_{\text{top-arrived}}
+8I_{\text{success}}
-10I_{\text{failure}}
\]

说明：

- 连续项只乘一次`dt=0.02`。
- 位移奖励不再额外乘dt。
- 登顶和终止奖励是一次性奖励。
- 同帧失败优先，不能同时领取成功或登顶奖励。
- 超时作为任务失败，支付-10。
- 平地与平台直接起步没有登顶事件，因此不领取+2。

`I_cruise`要求：

- 请求速度为正。
- 不处于减速或保持阶段。
- 当前指令已达到巡航目标。

### 5.2 水平面门控

新增水平面门控`g_level∈[0,1]`：

- 普通平地正常活动区域：1。
- 楼梯区：0。
- 四足投影均在同一顶部平台内，且机身超过平台前缘0.4米后，计时0.5秒，从0线性升至1。
- 条件失效时归零并重新计时。
- 判断使用真实地形，不使用带噪声地图。
- 不因短暂腾空将同一平台上的正常步态误判为楼梯。

足部抬脚目标另按每只脚投影所在表面判定：平台或接近平地为0.075m；楼梯上保持原楼梯目标。

### 5.3 权重和公式

设：

- `v_b`为机身系线速度。
- `v_heading`为世界速度在当前水平朝向上的投影。
- `ω`为机身角速度。
- `g`为机身系重力方向。
- `q₀`为原A2默认关节站姿。
- `H`为真实支撑面高度。
- `C_f`为原过滤接触状态。
- `a`为策略请求动作；关节跟踪使用真正执行的PD目标。

| 奖励项 | 未加权公式 | 巡航权重 | 减速/停车权重 |
|---|---|---:|---:|
| 前进速度跟踪 | `exp(-((vx_b-c_exec)²+vy_b²)/0.25)` | +1.5 | +1.5 |
| 偏航角速度跟踪 | `exp(-ωz²/0.25)` | +0.8 | +0.8 |
| 竖直速度 | `max(abs(vz_b)-0.15,0)²` | -1.0 | -1.0 |
| roll姿态 | `gy²` | -5.0 | -5.0 |
| 水平面pitch | `g_level×gx²` | **-5.0** | **-5.0** |
| 机身高度 | `(z_base-H-0.40)²` | -0.1 | -0.1 |
| 动作变化 | `Σ(a_t-a_t-1)²` | -0.01 | -0.01 |
| 默认关节姿态偏差 | `Σabs(q-q₀)` | -0.05 | -0.05 |
| 关节加速度 | `Σ((qdot_t-qdot_t-1)/dt)²` | -2.5e-7 | -2.5e-7 |
| 关节速度 | `Σqdot²` | -5e-4 | -5e-4 |
| roll/pitch角速度 | `ωx²+ωy²` | -0.05 | **-0.20** |
| 足部腾空时间 | 原首次落地结算，目标0.10s | +0.2 | **0** |
| 足部滑移 | `ΣC_f×‖vfoot_xy‖²` | -0.15 | -0.15 |
| 抬脚高度误差 | `Σ(1-C_f)(hfoot-h_target)²‖vfoot_xy‖` | -0.5 | -0.5 |
| 关节跟踪 | `Σ(q_target_applied-q)²` | -0.1 | -0.1 |
| 横向居中 | `min((local_y/0.20)²,4)` | -0.5 | -0.5 |
| 朝向 | `1-cos(yaw_error)` | -0.5 | -0.5 |
| 软关节越限 | 原上下限越界距离之和 | -10.0 | -10.0 |
| 水平面超速 | `g_level×max(v_heading-c_exec-0.15,0)²` | **-2.0** | **-2.0** |
| 稳定站立 | `I_stable×I_abs(c_exec)≤1e-7` | 0 | **+1.0** |

抬脚高度定义：

\[
h_{\text{foot}}=z_{\text{site}}-0.032-H(x_{\text{foot}},y_{\text{foot}})
\]

目标：

\[
h_{\text{target}}=
\begin{cases}
0.075,&\text{平地或顶部平台}\\
\max(0.17,h_{\text{step}}+0.02),&\text{楼梯}
\end{cases}
\]

对0.20m台阶，楼梯目标为0.22m。**不能继续因为tile属于楼梯，就在平台上也使用0.22m。**

停车请求发出时：

- 关闭前进位移奖励。
- 关闭腾空时间奖励。
- 清空腾空奖励累计状态。
- 不锁关节、不强制切换到手工站姿。

稳定站立瞬时条件：

- 水平速度≤0.05m/s。
- roll、pitch绝对值≤10°。
- 总角速度≤0.25rad/s。
- 机身离支撑面高度≥0.30m。
- 四足均有原定义的有效支撑。
- 四足平均水平速度≤0.05m/s。

### 5.4 普通平地保持损失

从S2.1开始：

\[
L=
L_{\text{PPO}}
+\beta_{\text{flat}}I_{\text{clean-flat}}
\operatorname{mean}[(\mu_{09}-\mu_{6400})^2]
\]

初始：

```text
beta_flat = 0.1
```

教师始终为原始6400，使用旧图；学生使用新图。

保持项仅作用于：

- 普通平地。
- 名义动力学。
- 无噪声、无延迟、无外力。

不得作用于楼顶异常状态或扰动病例，避免强行复制6400的缺陷或限制抗扰动动作。

### 5.5 物理终止规则

保持原物理规则：

- 身体接触。
- 非足部持续接触达到0.1秒。
- 原姿态越限和跌落条件。
- 越出实际有效地形。
- 接触溢出和非有限数值检查。

保留原楼梯行走通道限制，不能借加宽平台放宽楼梯侧向限制。顶部平台必须使用自己的真实几何边界；路线偏离另记任务指标，不把宽平台本身错误裁成0.8米宽。

合法地图无效点不触发“非有限输入”错误：高度填充值和valid通道必须按合同提供有限张量。

### 7.3 观测噪声目标范围

| 高程偏置 | 每回合Uniform[-0.01,0.01]m |
| 高程随机失效概率 | 每次刷新每点1% |

噪声σ、偏置范围、截断幅度和失效概率均乘当前α。

- 姿态噪声通过旋转施加，重力向量保持单位范数。
- 高程噪声只在10Hz刷新时生成，缓存间不重复抽样。
- 失效点按valid=0处理，不将其伪装成真实零高度。
- 奖励和验收使用真实仿真状态，不使用带噪声测量。

### 7.5 延迟实现规则

- 动作缓冲作用于真实执行器目标，不只是修改观测中的历史动作。
- 本体传感量使用同一采样时刻的完整测量包。
- 当前速度指令不随本体测量一起延迟。
- 历史动作字段记录实际施加动作。
- 地图保持采样时的坐标和高度参考，时效通道体现实际年龄。
- reset时初始化缓冲，不得混入上一回合的数据。
- 记录请求动作、施加动作及各自时间戳。
- 延迟不改变停车判定起算规则。

## 8. 门禁、回退与预算管理

### 8.1 检查点与门禁频率

- 每500万学习控制样本保存一次检查点。
- 预算≥2亿的行为课程，每5000万学习样本做一次门禁。
- 预算<2亿的行为课程，每2000万学习样本做一次门禁。
- S1.0为基线课程，不适用学习门禁。
- S1.1为固定适配课程，按第3.4节完成工程和数值检查。
- 其他行为课程均需连续两次门禁通过。

保存：

- 最新5份。
- 每课程晋级模型。
- 每阶段最终合格模型。
- 最近合格保持模型。
- 每1亿学习样本归档模型。

完整rollout不得使预算越界；不足一个完整rollout的剩余额度不强行使用。

### 8.2 普通平地退化回退

第二、三阶段连续两次门禁不满足平地保持标准时：

1. 保存失败现场和当前模型。
2. 恢复最近合格模型及其优化器状态。
3. 学习率减半，下限1e-5。
4. `beta_flat`翻倍，上限1.0。
5. 原课程继续，预算和回退消耗不清零。

同一课程最多两次这样的恢复。再次退化时提交规划裁定，不能自行：

- 删除平地保持项。
- 放宽成功率或姿态阈值。
- 更换初始化权重。
- 增加预算。
- 修改奖励配方。

第三阶段名义完整走停退化时，按同样规则回到本课程开始前的合格检查点，不提高扰动强度。

### 8.3 最终验收失败

预算尚有剩余时：

- 回到当前阶段最后一个行为课程继续训练。
- 保留失败验收结果。
- 下一次使用下一套预冻结最终病例。
- 不重复使用同一最终病例挑选最优checkpoint。

三套最终病例用完仍未通过，提交规划裁定。
