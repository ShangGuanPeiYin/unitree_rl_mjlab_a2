### 2.4 训练批次与优化参数

所有学习课程使用：

- rollout：48 个控制步。
- 每批数据：5 个 epoch。
- 每个 epoch：4 个逻辑 minibatch。
- 微批次最大 512。
- 按样本数加权累积梯度，一个逻辑 minibatch 只执行一次 Adam。
- FP32。
- 梯度裁剪：1.0。

第二、三阶段 PPO：

| 参数 | 数值 |
|---|---:|
| gamma | 0.99 |
| GAE lambda | 0.95 |
| PPO clip | 0.2 |
| value loss coefficient | 1.0 |
| clipped value loss | 开启 |
| entropy coefficient | 0.003 |
| Adam betas | 0.9、0.999 |
| Adam epsilon | 1e-8 |
| weight decay | 0 |
| 初始学习率 | 3e-5 |
| 学习率下限 | 1e-5 |
| 学习率上限 | 1e-4 |
| KL >0.02 | 学习率除以1.5 |
| 0<KL<0.005 | 学习率乘以1.5 |

### 3.2 网络迁移

原三层卷积后为 `32×6×4`，新图对应 `32×5×4`。

必须修改：

- Actor地图全连接层：768→64 改为640→64。
- Critic地图全连接层：768→64 改为640→64。

其他层维度不变。

两个变化的权重矩阵按以下方式初始化：

1. 原矩阵展开为 `[64,32,6,4]`。
2. 长度轴六个位置汇总为五个位置。
3. 新位置j对应旧坐标区间`[6j/5,6(j+1)/5]`。
4. 以该区间与旧单位区间的重叠长度作为权重系数，对旧权重求和。
5. 保留偏置，恢复为`[64,640]`。

该方法保留常量空间特征的权重和，但不是严格物理坐标对齐，不保证真实网络动作等价。教师看得到新视野以外的地形，存在新输入相同、教师动作不同的合成反例；因此蒸馏loss不必能降到0，预算也不保证行为恢复。必须按任务/速度报告动作和值损失以及行为门禁；若S1预算内无法恢复，保留证据并向规划报告，禁止自动加PPO、扩大视野、放宽门槛或进入S2。

## 4. 第二阶段：诊断、持续行走、停车

**课程数量：4 个。**

### 4.1 地形及任务定义

楼梯：

- 阶高0.20 m。
- 阶深0.20 m。
- 梯宽0.80 m。
- 前方接近平地保持原设置。

后方平台：

- 长20 m。
- 宽0.8 m或4 m，各50%。

普通平地使用与基线相同的普通平地，不将窄高台算成普通平地。

任务分为：

- `flat_walk`：普通平地行走20秒。
- `flat_stop`：前进8秒，停车，保持20秒。
- `stairs_walk`：上楼后在平台继续走指定距离。
- `stairs_stop`：上楼后走指定距离，再停车并保持20秒。
- `platform_walk`：从平台正常默认站姿起步，持续走指定距离。
- `platform_stop`：平台起步、行走、停车。

平台直接起步在平台前缘后1米，按真实顶面设置机身高度，不从楼底高度直接生成。该专项不能替代完整上楼验收。

### 4.2 指令、里程碑与结束规则

完整流程：

```text
APPROACH → CLIMB → TOP_TRANSITION → POST_WALK → DECEL → HOLD → SUCCESS
```

- 上楼成功条件仅生成一次`top_arrived`事件。
- `top_arrived`之后不reset。
- 以该事件时机身位置作为后续行走距离起点，`D_post=local_x(t)-local_x(top_arrived)`；不是路径长或累计正向位移。平台直接起步相对出生点计算。
- 不停车病例走够距离后才成功。
- 停车病例走够距离后发零速请求；完整保持窗口结束且任务质量判据全部合格才成功，不能只因存活20秒成功。
- 时序：控制步t开始读取已组装观测和`c_exec(t)`→Actor→延迟/执行器→4物理子步→更新状态、接触与奖励→锁存事件→设置下一步命令。距离触发在步末发生，突变从下一次Actor调用为0；ramp后续第k步`c_exec=v_cruise×(1-k/100), k=1…100`。
- HOLD从Actor首次收到0的控制时刻开始，连续1000步=20秒，不把2秒减速计入HOLD；末500步=10秒站立窗口。

指令：

- 突变：下一次策略调用直接收到零速。
- 渐变：100个控制步，由当前速度线性降至0；最后一个过渡步必须为0。
- 二者各50%。
- `vy=wz=0`。

明确记录：

- `c_request`：外部请求目标。
- `c_exec`：本控制步实际送入Actor的速度。
- `a_request`：Actor输出。
- `a_applied`：真正施加给执行器的动作。

停车恢复时间从`c_exec`首次为零开始计算，不能因为后续动作延迟而重新推迟起算点。

保持20秒，最后10秒为主要站立评价窗口。

任务超时：

\[
T_{\max}
=
\frac{2\left(L_{\text{approach}}+
N\sqrt{h^2+d^2}+L_{\text{arrival}}+D_{\text{post}}\right)}{v}
+T_{\text{ramp}}+T_{\text{hold}}+10
\]

- `L_approach`取实际出生点到第一阶的距离；分母v固定为该例正巡航速度0.3/0.5/0.6，不使用停车后的c_exec。
- 完整上楼`L_arrival=1.2m`，为原登顶机身≥前缘0.8m及确认过程留时；不能遗漏登顶前确认距离。
- 平台起步`L_approach=N=L_arrival=0`；普通flat_walk/flat_stop不用此公式，计划完成时刻为20秒/28或30秒；在该帧按完整窗口判成功或质量失败。独立硬防护timeout分别为20.02秒/28.02或30.02秒（多1控制步），仅状态机未正常结束时触发，预算使用这一硬上限。
- S1原楼梯超时仍按v07原公式；S2.1旧L40复习里程碑沿用原上楼硬时限。
- `T_ramp`为0或2秒。
- `T_hold`为0或20秒。
- 转换为控制步时向上取整。

登顶奖励不能替代最终任务成功。S2/S3的训练、门禁和终验共用一个每例质量判据：正常巡航窗口满足第6.5节姿态/速度条件，停车另满足完整HOLD、恢复与站立条件后才成功+8。已确定不可逆的质量事件（连续超阈、停滞、3秒未完成恢复等）即时锁存，继续到规定任务终点记任务失败-10；RMS/P99/均值/支撑比例仅在指定完整窗口闭合后计算并判定，期间为pending，不能用前缀统计提前锁死。物理失败立即终止并单独分类。没有有效巡航窗口不能成功。普通flat_walk持续20秒无停车，flat_stop按其自身窗口；不要求训练reward能直接代表质量。每例训练成功只取绝对轨迹质量；相对6400/S1/S2的成功数、分位数与均值保持是组级门禁/终验附加条件，不参与单回合奖励或终止。

同一控制步优先级：工程异常使本轮无效并停训排查；物理失败→质量失败/任务超时→任务成功→单独top事件。达到硬时限的同帧不能同时算成功。任务超时及质量失败均为`terminated=True,truncated=False`，GAE bootstrap=0；正常成功也不bootstrap。只有采样rollout边界或外部非任务截断才可bootstrap，不跨reset传播GAE。旧timeout_bootstrap合同不得照搬。

\[
r_t=
0.02\sum_i w_i f_i

+2I_{\text{top-arrived}}
+8I_{\text{success}}
-10I_{\text{failure}}

### 5.3 权重和公式

设：

- `v_b`为机身系线速度。
- `v_heading`为世界速度在当前水平朝向上的投影。
- `ω`为机身角速度。
- `g`为机身系重力方向。
- `q₀`为原A2默认关节站姿。
- `H(base_xy)`/`H(foot_xy)`分别为真实碰撞几何查询的表面高度，不能用最新接触高度、四足平均或出生高度代替；无支撑点按原有限填充值处理并记valid，不能伪造平台。
- `C_f`为原过滤接触状态。
- `a`为策略请求动作；关节跟踪使用真正执行的PD目标。

| 奖励项 | 未加权公式 | 巡航权重 | 减速/停车权重 |
|---|---|---:|---:|

### 5.4 普通平地保持损失

从S2.1开始：

\[
L=
L_{\text{PPO}}
+\beta_{\text{flat}}I_{\text{clean-flat}}
\operatorname{mean}[(\mu_{09}-\mu_{6400})^2]
\]

初始`beta_flat=0.1`。精确聚合为：

```text
L_anchor = sum_{i in clean-flat}(sum_j (mu_s[i,j]-mu_t[i,j])² / 12) / n_clean
L = L_PPO + beta_flat * L_anchor
n_clean == 0 时 L_anchor = 0
```

`n_clean`是整个逻辑minibatch的clean样本数；各微批只累计分子，统一除这个分母。不能各微批取mean后相加，也不能改除全部样本数导致S3保持强度暗减半。

教师始终为原始6400，使用旧图；学生使用新图。

保持项仅作用于：

- 普通平地。
- 名义动力学。
- 无噪声、无延迟、无外力。

不得作用于楼顶异常状态或扰动病例，避免强行复制6400的缺陷或限制抗扰动动作。

### 5.5 物理终止规则

保持原物理规则：

- 身体接触：原base_link接触力范数>0。
- 其他非足部接触力范数>10N，按0.005秒物理子步累计持续0.1秒。
- 原姿态越限70°、相对预期踏面跌落0.50m条件；保持原严格不等号与坐标定义。
- 越出实际有效地形。
- 接触溢出和非有限数值检查。

保留原楼梯行走通道限制，不能借加宽平台放宽楼梯侧向限制。顶部平台必须使用自己的真实几何边界；路线偏离另记任务指标，不把宽平台本身错误裁成0.8米宽。

满强度：

| 参数 | 分布 |
|---|---|
| 接触摩擦系数 | Uniform[0.45,0.80] |
| 每个刚体质量倍率 | Uniform[0.90,1.10] |

| 每关节电机强度倍率 | Uniform[0.90,1.10] |
| 每关节Kp倍率 | Uniform[0.90,1.10] |
| 每关节Kd倍率 | Uniform[0.90,1.10] |

每回合采样并固定。各环境独立。不得生成非正质量或非物理惯量。各刚体质量独立采样倍率；其自身质心处惯量乘同一倍率，惯量主轴保留。仅base_link偏移质心，惯量仍围绕新质心表示，不人为再加一遍平行轴项；其他刚体质心不偏移。

摩擦每回合每环境采样一个μ，作用于该环境最终足地接触的滑动摩擦；足碰撞priority=1，不能仅改低优先级地形字段。相关足/地碰撞参数须共同保证最终接触μ等于采样值，扭转/滚动摩擦与接触求解参数不变；验证实际接触参数和跨环境隔离。

电机强度作用在饱和前PD力矩，不是改变指令/动作缩放或只改上限：`tau=clip(s_motor*(s_kp*Kp0*(q_target_applied-q)-s_kd*Kd0*qdot), -tau_limit0,+tau_limit0)`。标称hip/thigh为Kp100、Kd4、限幅120；calf为Kp150、Kd6、限幅180，armature0.03保持。可以用等效的内置执行器gain/bias参数实现，不得更换动力学后端；实际输出需与公式对照。三类倍率独立采样且各只作用一次。

强度α按相对标称值插值：

```text
parameter = nominal + α × (sample_full - nominal)
```

### 7.5 延迟、噪声和观测历史的唯一时序

1. 每控制步t在Actor调用前，从仿真状态生成一次`ω_b、gravity_b、q-q0、qdot`完整传感包，按R4～R6加入噪声，保留采样时刻；从本体FIFO读取`t-d_prop`同一个包，不分字段独立抽延迟。
2. 拼接当前`t`的`command=[c_exec,0,0]`和上一物理控制区间真正执行的原始动作token`a_applied(t-1)`，构成45维。实际动作不是传感测量，不再额外延迟。命令不随本体一起延迟。
3. 将此45维仅写入一次5帧FIFO；历史帧保存它当时收到的指令/动作，不用当前指令覆盖旧历史，不对整个5帧历史再次延迟。
4. Actor生成`a_request(t)`，沿原动作缩放0.25和关节目标变换生成PD目标；将原始token及对应真实PD目标一起入动作FIFO；出队目标供随后4物理子步真正执行，不能重复缩放/限幅。D=0同一步执行，D=20/40ms分别落后1/2步；同时记录`a_applied、q_target_applied`。
5. 地图每5控制步采样一次，先采样真实几何、按当前课程加一次高度噪声/失效并缓存，再经过0/100ms额外FIFO；保存原采样位置、yaw和高度参考，不用出队时机身高度重算。时效通道按总年龄（含额外延迟）更新；无效点高度0、valid0、age1。
6. reset各FIFO复制该回合初始测量/默认站姿对应零动作token，时间戳不早于出生时刻；不借上回合数据，不虚构出生前噪声或未发生的地图延迟。地图初始帧可立即交付，后续进入规定延迟。

`route_error[3]`明确保留当前真实local_y/yaw，不加噪声或延迟；地图采样参考位姿仍是真值。它们是当前仿真任务的理想路线/定位条件，不宣称已验证完整实机感知链路。姿态噪声作用于重力方向，不偷偷噪声化路线旁路。Critic输入中的同名Actor观测使用同一份延迟/带噪声快照；privileged35保留原真值顺序与语义，不新增DR标签。

奖励和验收使用真值。延迟不改变停车判定的起算点。必须验证D=0时与无延迟合同一致、D>0实际改变执行器目标、各时间戳及采样刷新顺序正确。

## 8. 门禁、回退与预算管理

### 8.1 检查点、门禁和恢复预留

每500万**学习**控制样本保存checkpoint，阈值在下一个完整rollout结束触发。保存最新5份、各课程晋级、各阶段合格、最近保持合格，以及每1亿学习样本归档。阶段/课程切换立即保存。评估不增加训练iteration；失败/中断rollout已消耗部分照实计费，不拿其不完整数据做PPO。

| 阶段 | 主学习课程 | 正式门禁计划 | 最终失败恢复预留 |
|---|---|---|---|
| S1 | S1.1=2000万；S1.2主恢复6.3亿 | S1.2主段每1亿及主段末尾；两次恢复各5000万/1亿。阶段最多11次完整门禁 | 最多两次，每次1亿，计入S1.2总8.3亿 |
| S2 | S2.1=8亿；S2.2=12亿；S2.3=12亿 | 主段与恢复每1亿；额外4次仅用于末尾/冻结候选A/B确认，总最多40次 | 最多两次，每次2亿，只继续S2.3；阶段学习总36亿 |
| S3 | 表7.4、7.6共19个子级，主学习共40亿 | 每子级在40%、80%、100%学习cap触发，最多3次；恢复各1亿/2亿，阶段最多61次 | 最多两次，每次2亿，只继续R13的0.20m/s子级；阶段学习总44亿 |

一次门禁为当前课程规定的完整病例集合的A或B一套，不是一个组合。晋级要求同一候选SHA在相邻A/B均通过：首次通过后立即冻结候选并跑另一套，确认占下一次计划的门禁名额和费用，并取消对应未来一次门禁；不能额外免费增加次数。两次都通过则晋级，不在确认之间训练；确认失败解冻继续训练，待下一计划阈值。次数不足两次/阶段剩余预算不足时不宣告通过，应提交裁定。

S1.0、S2.0不适用学习门禁；S1.1仅做定义的工程/数值验收。所有正式门禁开始前检查预留账本；实际费用少于上界的余量可供同阶段既定工程/异常重跑，不能自行添加新的最终集、正式门禁次数或训练cap。未用课程预算不自动挪到下一课程。达到课程cap仍未晋级就停下请求裁定，不以剩余阶段资金为由自动续训。

固定N下，一次学习迭代=`N×48`样本、20次逻辑Adam；因此“训练多少迭代”由最终资源档位计算并在命令/报告显式列出。2048/1536/1024/512环境分别为98304/73728/49152/24576样本每迭代；各cap取整下界，不允许为了刚好凑整数超预算。所有门禁学习阈值先映射到可达完整rollout边界；100%/课程末尾使用`effective_cap=floor(cap/(N×48))×(N×48)`。中间阈值和检查点可在跨越后的第一个完整rollout触发，但不得越effective_cap；同一边界的末尾/周期/冻结确认事件去重，不重复消耗一次门禁的名额。改变N仅影响尚未执行的剩余段边界，已消费样本和已触发门禁不重新取整或撤销；剩余额度不足完整rollout仍按第2.5节处理。

### 8.2 回退规则

S2/S3连续两次正式门禁不满足平地保持时：保存失败证据→恢复最近保持合格模型/优化器→LR减半（≥1e-5）→beta_flat翻倍（≤1.0）。同课程最多两次恢复；再退化提交规划裁定。恢复使用当前课程剩余学习cap，不另外增加预算；若没有保持合格的中间checkpoint，恢复课程入口合格checkpoint。

S3名义完整走停或已通过方向复习连续两次门禁失败时，恢复本子级入口合格checkpoint，并按同样LR/beta规则及共享“两次恢复”计数处理，不升强度。S1不自行套用PPO回退或加RL。不能删保持项、放宽阈值、换来源、增加预算或改奖励。

普通训练rollback与最终验收重试是不同原因但共用实际消费总账；不能靠先rollback再resume清除失败计数或取回额度。恢复后门禁计数、A/B下一套、最终集已使用状态和下次门禁阈值不倒退；清空旧候选连续通过状态，不能混用回退前的通过记录。

### 8.3 最终验收与不倒退账本

每阶段两次同SHA门禁后运行下一套冻结终验。候选因行为失败后，保留结果并消耗一套最终集，仅可启用该阶段下一段预留恢复额度；修复后仍需两个同SHA门禁，再跑下一套。最多三套；全部用完或预留不足即向规划报告。候选不得用同一最终集反复选模。工程异常重跑规则见第2.2节，也需要非学习余量。

外部只追加账本以唯一`run_id/segment_id/operation_id`记录实际环境控制步、类别、N、阶段/课程、checkpoint与原因。rollout/门禁/资源探测启动前原子预留其最坏成本，完成后提交实际量、释放余量；中断保留实际量，未知是否完成的操作按预留上界保守结算后人工核对，不能重新免费执行。

回退消耗是已消费记录的属性，不另加一次重复收费。模型/优化器可回退，累计预算、恢复次数、最终病例使用记录不可回退。阶段入口因证据充分而降低N时，保留模型/优化器与全局课程、费用、门禁状态；按新N重建角色、RNG和新物理回合缓冲。随机流由全局seed、角色、单调episode_id派生，不依赖slot编号或当前N；改变N不得重置到相同一批旧episode。保存前后元数据，不能使用“当前N×历史update数”重算费用。
