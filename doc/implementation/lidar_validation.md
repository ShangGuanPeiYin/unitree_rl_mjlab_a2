# 双雷达实现与有限验证

2026-11-10。本记录仅包含静态射线和合成张量测试，不代表动态爬楼、训练或8096容量通过。

## 实现

每台雷达128×64方向，seed42固定置乱分为五组（1639/1639/1638/1638/1638）。前后位置±0.45、0、0.10 m，分别朝前/后，下俯30度；没有调整SDS外参。配置仅注册两个传感器，自动sense的射线调用为空，由环境在指定策略时刻显式扫描一次；每环境按独立组号选取1639槽，短组padding有独立无效mask。因此不是注册十个传感器后每步扫描所有五组。

MuJoCo实际A2碰撞geom属于group3，楼梯group0，扫描明确包含(0,3)，不排除父body。先找第一命中再过滤机器人返回，机器人仍然遮挡后方地形。公开mjlab RayCastData不含geom id，适配器使用固定mjlab接口的内部命中ID；版本改变需要复验。

点云经过有效距离、机器人命中、有限值和ROI过滤，再按0.10m体素求均值。前后优先各35，剩余配额转给另一侧；总计不足70填无效槽。体素均值按128环境分块scatter，不逐环境调用torch.unique。每个batch内部按有效体素顺序均匀取样，无重复体素；这属于确定性采样实现细节，未增加点数。历史保留采样时机身坐标，不用真值配准；年龄包含2或3步延迟，异步reset清空指定环境队列和扫描组。
