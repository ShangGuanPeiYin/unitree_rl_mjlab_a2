# S2 奖励接入审计清单（重跑准入）

用途：S2.1/S2.2/S2.3 训练重跑前，独立验收必须逐项核对本清单。背景见 `docs/v09_s2_1_r1_invalidated.md`（v07 奖励误用导致 20,275,200 样本作废）。

## A. 调用链

- [ ] `S2TrainEnv` 的 `_reward` 不再等于 `V07Env._reward`/`reward_computer`；训练路径只调用 `s2_rewards.compute_reward`（或等价 S2 实现）。
- [ ] 无残留 `reward_computer` 输出进入 PPO（grep `reward_computer`、`V07` 奖励项）。
- [ ] 奖励返回形状 `(N,)`、dtype float32、finne 检查。

## B. 总公式（§5.1）

- [ ] `r = 0.02·Σ w_i f_i + 0.4·Δx·I_cruise + 2·I_top + 8·I_success − 10·I_failure`。
- [ ] 连续项只乘一次 `dt=0.02`；位移项不乘 dt。
- [ ] 同帧失败优先：失败帧不得同时得 `+2/+8`；超时按失败 `−10`。
- [ ] 登顶只付一次；`top_arrived` 后不重复 `+2`。

## C. 权重与项（§5.3，两列）

- [ ] 20 项权重与 §5.3 表逐项一致；巡航/减速停车两列分别取值。
- [ ] `pitch` 项 `−5·g_level·gx²`；`超速` 项 `−2·g_level·max(v_heading−c_exec−0.15,0)²`；同帧同一 `g_level`。
- [ ] `g_level` 时序按 Q027/Q028/Q032（t0=0、t0+1=0.04、t0+25=1；失败同帧归零重定；平地=1、楼梯=0）。
- [ ] `stable_stand` 仅 `|c_exec|≤1e-7` 帧付 `+1`；DECEL/HOLD 且 c_exec>0 不付。
- [ ] 抬脚目标按逐足真实表面（平台/平地 0.075、楼梯 0.22）。
- [ ] 停车请求时关闭前进位移与腾空奖励并清累计；不锁关节、不切手工站姿。
- [ ] `I_cruise` 三条件（正速度请求、非减速/保持、指令已达巡航目标）。

## D. 状态与观测来源

- [ ] `c_exec` 为真正送入 Actor 的延迟后命令（非 `c_request`/非采样命令直读）。
- [ ] `c_request/a_request/a_applied` 时序与 S2.0 一致。
- [ ] `H(base_xy)`/`H(foot_xy)` 用真实碰撞几何查询（非硬编码 0.2/0.0），无效点按合同处理并记 valid。
- [ ] 接触用 `C_f` 过滤接触；非足部接触按 §5.5 计时。

## E. 测试

- [ ] 分项手算对照：构造状态逐项验算 20 项与总奖励。
- [ ] `−10`（失败/超时）、`+8`（成功）、`+2`（登顶一次）、失败优先的断言。
- [ ] 停车段：前进/腾空为 0、`stable_stand` 条件、清累计。
- [ ] `g_level` 序列（t0/t0+1/t0+24/t0+25、失效重入）。
- [ ] 训练 rollout 奖励非零、非 v07 输出（可对同一状态比较两实现）。
- [ ] 512/1024 预算与 rollout 上限断言不变。

## F. 证据与重跑

- [ ] 修复前后同一状态的 S2 奖励分项对照表（含与 v07 的差异）归档。
- [ ] `s2.1-r1` 检查点保持作废；重跑 `s2.1-r2` 从 `s1_least.pt` 开始。
- [ ] 重跑命令含 `--course S2.1 --num-envs 512`、剩余额度 31,727 rollouts。
