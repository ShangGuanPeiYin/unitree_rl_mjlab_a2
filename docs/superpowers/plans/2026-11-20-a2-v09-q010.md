### Task 1: 共享证据身份验证器（root）

**Files:** Create `src/tasks/velocity/v09/evidence_identity.py`；Create `tests/test_v09_evidence_identity.py`；Modify `doc/sds/reviews/v09_execution_rulings.md`（仅追加Q010，Task 0后）。不修改原基线/校准生产入口或cases生成算法。

**Interfaces:**

```python
EvidenceIdentityContext.from_approval(
    approval_path, approval_sha256, *, consumer_code_sha256,
    run_id, run_dir, ledger_path, sds_sha256, source_sha256)
ctx.expected_ref(path, *, kind, suite) -> EvidenceRef
ctx.verify_ref(path, *, kind, suite, manifest_sha256=None) -> EvidenceRef
ctx.read_legacy_bytes(path, *, kind, suite,
    manifest_sha256=None, candidate_sha256=None) -> tuple[bytes, EvidenceRef]
ctx.read_legacy_json(path, *, kind, suite,
    manifest_sha256=None, candidate_sha256=None) -> tuple[dict, EvidenceRef]
ctx.read_manifest(path, *, purpose, suite,
    candidate_sha256=None) -> tuple[dict, EvidenceRef]
```

`EvidenceRef`是frozen dataclass，字段使用可JSON序列化的基本类型，可直接`dataclasses.asdict(ref)`；只含原producer、唯一consumer、run、路径、kind/suite、内容SHA、manifest引用及批准清单SHA。Context公开只读`approval_path`、`approval_sha256`、`run_dir`、`run_id`、`ledger_path`、`consumer_code_sha256`属性，供父进程构造子命令，不访问私有字段。`expected_ref`只查可信catalog，不读取artifact；`verify_ref`stream hash-only，不返回原文；读取方法校验后返回同一份bytes/其解析结果，不重开文件。baseline索引为多manifest元数据引用，`suite=None`，可未解封读取；单manifest引用和多manifest引用在清单中明确区分。

清单在r3等snapshot外，由独审在新源码freeze后生成，避免自引用。清单绑定唯一旧447→唯一新完整SHA、同run及resolved路径、SDS/6400、显式允许的文件/种类/suite、内容SHA、冻结病例输入、旧source归档/依赖证明、原账本闭合前缀、逐文件diff及独审结论。不得通配、传递或通用忽略SHA；缺任一兼容参数即拒绝旧producer。冻结输入与旧运行证据分栏，S1_DIAG只可作为原冻结输入，不许可旧DIAG结果。

`read_manifest`从批准`frozen_inputs`目录项取得可信manifest SHA，再对同一已验bytes解析并调用现有 `cases.validate_manifest`，保持原purpose限制，无须改cases生产实现。冻结manifest没有自身`code_sha256`，不能套用普通旧JSON必须含producer字段的检查。final原文读取必须先以真实candidate SHA、此Context的run/ledger调用实际 `s1_runner.validate_final_unseal`；禁止allow_final/unsealed布尔豁免。final的hash-only检查可不解封原文。冻结ledger前缀仅为旧身份锚点；实际final资格必须fresh读取活ledger及当前journal，绝不能使用冻结时学习0/门禁0的旧计数。
